# Локальные ресурсы Swagger UI

Официальный `swagger-api/swagger-ui`, релиз **v5.36.0**, получен 23.11.2026.
Ресурсы находятся отдельно от собственного frontend-кода и не изменяются вручную.
Источник и SHA-256 каждого файла зафиксированы в `manifest.json`; лицензии —
`LICENSE` и `NOTICE.txt`. Тест проверяет контрольные суммы. При формировании
контейнера каталог входит в `COPY src`; CDN и npm на сервере не требуются.

`swagger.js` настраивает только нашу `/api/openapi.json`, отключает внешний
validator и сохранение авторизации. Серверные ключи в документацию не передаются.
