Авторизация

X-API-Key — собственный ключ интеграции. Idempotency-Key — стабильный ключ повторяемого запроса. Для импорта каталога нужен отдельный X-Catalog-Key.

Cookie web-сессии требует CSRF и Origin для записи. Серверные ключи не передаются этой странице; введённая в Swagger авторизация не сохраняется после закрытия.
