API и интеграция

1С и Telegram — независимые API-клиенты mapper. Каждый использует свой X-API-Key; исходная пятёрка документа остаётся неизменной.

Основная последовательность

  1. Передать готовый документ в POST /api/v1/mappings/import-json с Idempotency-Key.
  2. Получить статус и Top-5, сохранить выбор или явный null с актуальной revision.
  3. Вызвать approve и скачать approved.json до expires_at.

Polling spec-extracting-ai поддерживается отдельно по UUID. Ключ извлечения должен владеть upstream заданием. В web-сессии API-задания другого владельца не открываются.

Источник справочника 1С

Локальный XML работает сейчас. HTTP-источник требует согласованного полного XML, авторизации, allowlist и признака завершённости. Статус ожидания контракта не означает успешного подключения.
