Доступ оператора

Для управления общим справочником нужна короткая операторская сессия. Обычная web-сессия и API-ключи интеграций таких полномочий не дают.

Как получить защищённый доступ

На HTTP-адресе в LAN ввод кода отключён. Создайте SSH-туннель и откройте localhost:

ssh -N -L 18087:127.0.0.1:8087 main@192.168.55.3

В другой SSH-сессии создайте одноразовый код (он не является API-ключом):

cd ~/projects/spec-mapper-ai
docker compose --env-file .env.example --env-file .env exec -T api /app/.venv/bin/python -m src.cli operator-ticket

Откройте http://localhost:18087/operator через этот туннель. Код действует ограниченное время и используется один раз. Для постоянного HTTPS-доступа обратитесь к оператору инфраструктуры.
