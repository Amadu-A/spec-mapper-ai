Открыть вход через SSH-туннель

Введите свой логин сервера. Выполните команду один раз в отдельном терминале и оставьте его открытым:

Загрузка адреса SSH-входа…

Затем откройте http://localhost:18087/operator. На этой странице появится кнопка получения кода. Дополнительная SSH-команда для его выдачи не нужна.

Старый туннель на порт 8087 остаётся обычным web-доступом. Для кнопки получения кода используйте показанный loopback-порт оператора.

Резервный способ через CLI

Если используется настроенный HTTPS или прежний туннель, код по-прежнему можно получить в SSH-сессии:

cd ~/projects/spec-mapper-ai
docker compose --env-file .env.example --env-file .env exec -T api /app/.venv/bin/python -m src.cli operator-ticket
